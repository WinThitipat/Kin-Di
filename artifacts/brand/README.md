# KIN DI logo

Primary: kindi-logo.svg (outlined vector), kindi-logo.png (transparent, 1600px wide).
Variants: kindi-logo-black, kindi-logo-white, kindi-icon.

Wordmark: Kanit SemiBold, with KIN DI in IBM Plex Sans Thai Medium. All SVG lettering is converted to paths; no font installation is required to display the files. Font license files are included in source/Kanit-OFL.txt and the project's public/fonts/OFL.txt.

Keep the proportions unchanged. Use the red version on white or warm ivory, the white version on solid dark surfaces, and the black version for monochrome printing. Keep clear space of at least one exclamation-dot height around the logo. Use the icon for small square contexts; use the full lockup at 120px wide or greater.

This is a proposed logo asset set. The website's current logo has not been replaced.
