## สิ่งที่แก้ในส่วนรายการเมนู
- เอาปุ่มดูเมนูยาวเต็มแถวออก ใช้ลิงก์ใกล้ชื่อและรูป
- เปลี่ยนถาดปุ่มจัดการแนวนอนเป็นเมนูแนวตั้งแบบลอยยึดกับปุ่ม
- เปิดเมนูแล้วความสูงแถวไม่เปลี่ยน เปิดได้ครั้งละหนึ่งเมนู ปิดเมื่อกดด้านนอกหรือ Esc
- เอา scrollbar ซ้อนในรายการออก เพื่อไม่ตัดเมนูลอย
- ตรวจด้วย design-taste-frontend และดูภาพจริงทั้งตอนเปิด/ปิด ไม่อ้างว่า inspector ผ่านเท่ากับ UX สมบูรณ์

## ความซื่อตรงของชุดทดสอบ
verify-detail-edit.cjs เดิม timeout เพราะรอปุ่มขั้นตอนในสูตรที่เป็น source notes เท่านั้น ตรวจ source และ UI แล้วยืนยันว่าพฤติกรรมปัจจุบันถูกต้อง จึงปรับเทสให้แยก source notes กับขั้นตอนจริง และทดสอบ edit/PIN ต่อจนผ่าน ไม่ได้นับผล timeout เดิมว่าเป็น pass

## ขอบเขตและสิ่งที่ยังพิสูจน์ไม่ได้
- ใช้ Chrome headless desktop และ viewport/touch emulation ไม่ใช่โทรศัพท์ iOS/Android จริงหรือ Safari/Firefox
- ไม่ได้ทดสอบผู้ใช้จริง จึงยังไม่รู้ว่าคนใหม่จะเข้าใจคำว่าไพ่/ข้อจำกัดได้เร็วเพียงใด
- ไม่ได้ทำ load test, DDoS simulation, penetration test หรือรับรองความปลอดภัยของฐานข้อมูล
- ไม่ได้เขียนสูตรหรือทดสอบ PIN จริงบน production ในรอบ QA เพื่อไม่สร้าง/ลบข้อมูลจริง; การเขียนใช้ mock API จึงไม่ได้พิสูจน์ persistence ของ production รอบนี้
- ไม่ได้เปิดสูตรภายนอกทุกลิงก์ ไม่ได้ตรวจลิขสิทธิ์ภาพหรือความถูกต้องเชิงโภชนาการ/สารก่อภูมิแพ้
- ยังไม่ได้ตรวจ WCAG เต็มชุด, screen reader, zoom 200%, offline, network disconnect ระหว่างบันทึก หรือ browser history ทุกแบบ
- การไม่พบรูปเสียไม่ครอบคลุม lazy images ทุกเมนูหรือทุกสถานะ
