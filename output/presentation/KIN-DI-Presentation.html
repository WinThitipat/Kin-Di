KIN DI / ข้อมูลเก็บที่ไหน09

เทสอะไรไปแล้วบ้าง

ใช้งานได้แค่ไหน
ยังมีอะไรต้องทำต่อ

ส่วนที่เทสแล้ว

  • Unit test และ API test บางส่วนด้วย Vitest
  • Playwright ตรวจ flow บน Chrome
  • เทส responsive ตั้งแต่ 320 ถึง 1440px
  • จำลองโหลดช้า ล้มเหลว และลองใหม่
  • ลองเซฟวัตถุดิบ แล้วเปิดดูจาก browser ใหม่

ส่วนที่ยังต้องพัฒนาต่อ

  • ยังไม่มี login และ sync ข้อมูลส่วนตัวข้ามเครื่อง
  • บางสูตรต้องอ่านวิธีทำจากเว็บต้นฉบับ
  • ยังไม่ได้ทำ load test และ penetration test เต็มรูปแบบ
  • Filter ช่วยคัดเบื้องต้น ยังต้องเช็กส่วนผสมจริง
